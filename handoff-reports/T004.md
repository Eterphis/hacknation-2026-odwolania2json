## What was built
- `odw2json/engine/` (generic, no class names; AC-3 grep is clean):
  - `text.py`: `fold()` (casefold + strip diacritics, one char per char, so offsets in folded text are offsets
    in the original text), `squash()`, and `Text`: document lines built from word boxes (via
    `ingest.layout.group_lines`, blank line between blocks as in `build_text`) or from `page.text` when a page
    has no boxes. `Text.locate(start, end)` gives page + bbox of any text span.
  - `recipes.py`: `load_recipes(dir)` validates each YAML against `recipes/recipe.schema.json`
    (Draft 2020-12) and compiles every regex; errors name the file and the JSON path
    (`zly.yaml: classify/signals/0/pattern: 3 is not of type 'string'`). Recipes dir: `--recipes` CLI option >
    env `ODW2JSON_RECIPES` > `./recipes`. Dictionaries: `dictionaries/<name>.yaml` (`entries: [{id, label, triggers}]`).
  - `engine.py`: `RecipeEngine` implements both `Classifier` and `Extractor`. It reloads recipes when a file in
    the directory is added/edited/removed (new YAML = new class, no restart).
    - Classification: weighted signals (`pattern`, `weight`, `head: N` = first N chars, `squash: true` = matched with
      whitespace removed, for letter-spaced headings and OCR that drops spaces), `required`, `forbidden`,
      `min_score`, `margin` over the runner-up. Otherwise reject (`doc_class=None`, reason filled).
    - Extraction: fields with ordered strategies; first candidate that survives the normalisers wins.
      `section:` scoping (sections cut by start/end patterns, nested with `within`), `list_of_blocks` groups
      (one list item per block), `all: true` on a `list[].field` path (every distinct match = one item).
      Every value gets an `Evidence` (path, value, page, snippet, rule, confidence, bbox). Confidence: 1.0,
      x0.5 when its validator fails (value kept), x0.9 on OCR pages. Output completed with the schema skeleton
      (`output_schema` in the recipe, else `schemas/<class>.json`).
  - `strategies.py` (registry, `register_strategy`): `regex` (group `v` or 1), `after_label` (right of the label
    up to the next column gap, else the line below inside the label's column using word boxes: handles the
    two-row bank grid and label/column layouts; `value:` regex filter; `max_lines` continuation aligned in the
    column; labels treat a space as optional whitespace), `between`, `lookup` (dictionary trigger occurring first
    in scope wins), `const`, `derived` (`if_set` sibling path -> value/else).
  - `normalise.py` (registries): `date_pl`, `amount_pl`, `digits`, `int`, `iban_pl`, `ted`, `bzp`, `strip`,
    `unquote`, `upper`, `title`; validators `nip`, `regon` (9/14), `pesel`, `krs`, `iban` (mod 97).
- `recipes/recipe.schema.json` + `recipes/{odwolanie,pelnomocnictwo,przelew}.yaml`: classification complete for the
  three classes, przelew fields complete, a first set of fields for odwolanie and pelnomocnictwo.
- `dictionaries/czynnosc_powod.yaml`: ids 1-11 with labels and trigger phrases (12 unknown).
- `odw2json/factory.py`: defaults switched to the T003 ingestor (`odw2json.ingest.default_ingestor`) and one
  shared `RecipeEngine` as classifier + extractor. `odw2json/cli.py`: `--recipes` option.
- `tests/test_engine.py` (16 tests): a fake class `zamowienie_pizzy` defined only by YAML + JSON skeleton +
  dictionary in a temp dir, classified and extracted from a synthetic word-box `Document` (all strategies,
  two-row grid, list_of_blocks, checksums, evidence bbox), reject/forbidden, letter-spaced heading, hot reload of a
  new YAML, invalid recipe errors, normalisers/validators, fold, factory defaults, TED reject + OCR appeal on
  the shipped recipes.

## Decisions
- Patterns are written in folded form (no diacritics, lower case) and matched with IGNORECASE|MULTILINE on the
  folded text; values are cut from the original text at the same offsets, so they keep diacritics.
- `after_label` uses word geometry: the first gap after the label is the label/value gap, the next big gap
  (> max(12 pt, 1.5 x line height)) starts another column; a lone label followed by another column's label falls
  through to the line below, restricted to the label's column.
- Margin rule: winner must lead the runner-up by `margin` (1 in shipped recipes), else reject as ambiguous.
- New class = recipe YAML + output JSON skeleton (`schemas/<class>.json` for the pipeline writer, or
  `output_schema` in the recipe for the engine alone). The pipeline still calls `write.complete(data, class)`,
  which requires `schemas/<class>.json`; not changed (pipeline/writer are T001's).
- `engine.py` reuses `write._fill` (private) so engine and writer share one completion rule; a public alias in
  `write.py` would be cleaner (left alone: not my file).
- The synthetic data has a typo "unieważniił"; the dictionary trigger is `unieważni\w*ł postępowanie`.
