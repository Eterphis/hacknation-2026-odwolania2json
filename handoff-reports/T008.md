## What was built
- `Dockerfile`: python:3.13-slim, CPU only, `libglib2.0-0` + `libgomp1` for OpenCV/ONNX Runtime, RapidOCR models
  fetched at build time (OCR works offline at run time), web UI by default on 0.0.0.0:8000. No Tesseract layer:
  T003 ships RapidOCR only (a Tesseract backend can be registered later via `register_backend`).
- `docker-compose.yml`: `web` (port 8000, `recipes/` and `dictionaries/` mounted read-only, so recipe edits hot
  reload) and `cli` (profile `cli`, mounts `./input` read-only and `./output`): `docker compose run --rm cli`.
- `.dockerignore` keeps data, outputs, `.house/`, `house/`, tests, docs, venvs and secrets out of the image.
- `start.bat`: creates `.venv` (py -3.13, else python), installs `requirements.txt` once (reinstalls when the file
  changes: a copy is kept in `.venv/requirements.installed`), runs the CLI on `.\input` -> `.\output` (extra args
  passed through); `start.bat web` starts the UI on 127.0.0.1:8000. `.gitattributes`: `*.bat` CRLF.
- `.github/workflows/ci.yml`: Python 3.13 on ubuntu, installs requirements, runs the unit tests (UZP-data tests
  skip themselves) and validates the recipes.
- Docs: `README.md` (product, Polish; quick start for start.bat / Docker / Python, output contract, quality section
  with placeholders for the 41-60 numbers until T005/T006 are merged, screenshots marked as mock), `docs/ARCHITECTURE.md`
  (mermaid flow, modules, data model, decisions D-005 / config-only classes / reject / confidence, extension points,
  env vars; planned items marked), `docs/ADDING_A_DOCUMENT_CLASS.md` (tutorial with a YAML-only `faktura` class and a
  full recipe reference), `docs/EXTERNAL_COMPONENTS.md` (every direct and main transitive dependency with version and
  licence, the self-hosted fonts Anybody and Martian Mono (SIL OFL 1.1) and the Cold Trace kit, runtime image; explicit
  "no AGPL/GPL" statement with the rejected AGPL/GPL candidates).
- `tests/test_docs_recipe_reference.py`: fails when a registered strategy/normaliser/validator is not described in
  ADDING_A_DOCUMENT_CLASS.md (keeps the reference in sync with the engine registries). The T005 additions
  (`segments`, `min_blocks`, `merge`) are already described there and marked "after merging T005".
- The old house README content moved to `TEAM.md` ("Repo layout (team view)").
