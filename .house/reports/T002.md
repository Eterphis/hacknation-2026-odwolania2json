## Goal
`python -m eval.score` = local copy of the hidden F1 (task T002-local-scorer.md).

## What was done
- `eval/score.py`: pure stdlib. Document type from top-level keys; leaf-level micro F1; lists and same-type
  documents aligned by Hungarian assignment on leaf agreement (ties broken by fewer errors); exact and normalized
  equality. Output: per-type table, `normalized: x`, last line `score: x` (4 decimals). `--report` writes a markdown
  report with per-type, per-field P/R/F1, worst fields and worst cases.
- Full definition in the module docstring and `eval/README.md`.
- `tests/test_score.py`: 17 unit tests on inline fixtures (no gold copied): type detection, equality modes, wrong
  value = FP+FN, list alignment independent of order, missing/extra documents, same-type pairing, case/type
  filters, CLI last line and report.
- Decisions on unspecified points: unknown-type pred file = extra document (all FP); invalid-JSON pred file is
  skipped with a warning (counts as missing); pred cases absent in gold are ignored; `Zamawiajacy` and
  `ZamowieniePubliczne` keys also map to odwolanie.
