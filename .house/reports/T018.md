## Design
- `dedupe: {fuzzy: N}` on a list field (`list[].key`, `all: true`, or a list merged by `list_of_blocks.merge`). New module `odw2json/engine/dedupe.py`: names are equal after casefold + diacritics fold + single spaces, or within N Levenshtein edits. Kept form: mixed case over ALL CAPS / lower, on a tie the later one (signature). Recipes use `dedupe: {}` (fuzzy 0, folding only; follow-up from the coordinator: `fuzzy: 1` would merge `Jan Kowalski`/`Jan Kowalska`; a unit test keeps them apart). Used on pelnomocnicy (both rules) and mocodawca podpisujacy (body rule and signature merge).
- `attach_to: list[].key` (+ `window`, default 200) on a field `list[].field`: the strategies run per list item, in the text after that item's mention up to the next item's mention. The first mention that yields a value wins (a letterhead may repeat the name). Used for `pelnomocnicy[].pesel` (`pesel\W{0,3}\d{11}`, `validate: pesel`, window 150). Handles "(radca prawny, nr wpisu X, PESEL: ...)", "nr wpisu ..., PESEL", "r. pr. Name, PESEL 8507..." and keeps each PESEL with its own attorney.
- `person` normaliser splits glued tokens (`HalinaBaran` -> `Halina Baran`: every part upper-case first letter and >= 2 letters; `Mc`/`Mac` prefixes are kept). Only person fields use it; `company`/`strip` untouched (`BudMax`, `ePUAP`, `eKRS` stay). The mocodawca podpisujacy body regex also accepts a glued name; the title rule for pelnomocnicy now uses `person` instead of `strip`.
- Odwolujacy section now ends at `Wykonawca wybrany`, `uczestnik (..)/postepowania/po stronie`, `Przystepujacy`.
- Schema (`recipes/recipe.schema.json`) and `docs/ADDING_A_DOCUMENT_CLASS.md` updated; `tests/test_engine_people.py` (9 tests, written first).
