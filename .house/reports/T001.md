## Goal
Runnable `odw2json` package implementing the UZP contract end to end with stub logic (task file: .house/tasks/T001-skeleton-cli.md).

## What was done
- `odw2json/write.py`: `skeleton(class)`, `complete(data, class)` (missing keys -> null, unknown keys dropped, empty lists -> one all-null item, multi-item lists kept and completed), `write_json` (UTF-8, `ensure_ascii=False`, LF).
- `schemas/{odwolanie,pelnomocnictwo,przelew}.json`: null skeletons generated once from the UZP reference schemas (same keys, one template item per list).
- `odw2json/pipeline.py`: `process_case` (no file writes, for the web UI) and `process_input` (writes `<output>/<case>/<basename>.json` only for accepted docs). One failing PDF becomes a warning on its `DocumentResult`, never a crash.
- `odw2json/factory.py`: default ingestor/classifier/extractor; later tasks swap the stubs here.
- `odw2json/stubs.py`: pdfplumber text ingestor, keyword classifier (przelew / pelnomocnictwo / odwolanie, reject otherwise), null-skeleton extractor.
- `cli.py`, `__main__.py` (`--input` default `./input`, `--output` default `./output`), `start.bat`, `input/.gitkeep`, `output/.gitkeep`, `.gitignore` additions. `requirements.txt` already had pdfplumber; not touched (T003 appends).
- 20 unit tests in `tests/`.
