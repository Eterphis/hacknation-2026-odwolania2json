## What was built
- Pipeline/CLI: every input PDF gets `<name>.json`; a rejected or unreadable document gets `{}`.
  `--rejected-json {}|empty|none` (env `ODW2JSON_REJECTED_JSON`): `empty` = 0 bytes, `none` = old behaviour.
  Default `{}` (valid JSON with no leaves; UZP says only "pusty plik .json"; flagged for the owner).
- Negatives: odwolanie `forbidden` signal for KIO rulings (header "Sygn. akt: KIO … POSTANOWIENIE/WYROK",
  "Krajowa Izba Odwoławcza - w składzie", "Przewodniczący:") in the first 1200 chars. 16/16 negatives -> `{}`.
- Code 12 "Projektowane postanowienia umowy" + official labels (code 6 text).
- **OCR reading order** (`odw2json/ingest/layout.py`, generic, affects scans only in practice): lines grouped by centre
  distance with a non-growing band, and a word never joins a line it overlaps horizontally. Before, a slightly skewed
  OCR line's tall box swallowed the neighbouring lines ("Asterion do 999-295-65-50, rejestru Budownictwo…").
- Engine (generic, unit-tested): `regex` strategy `raw: true` (case-sensitive on the original text); list_of_blocks
  `merge` adds only list items not present yet; normalisers `person` (ALL-CAPS name -> "Jan Kowalski-Nowak"),
  `company` (OCR "Sp. z 0.o." -> "Sp. z o.o."), `ocr_digits` (o/O -> 0, l/I -> 1 before digits).
- pelnomocnictwo recipe for the real (scanned) letters: principal "X z siedzibą w …"; signatories from "reprezentowana
  przez: X – Prezes Zarządu, Y – Prokurent" (per consortium member) and "Dokument podpisany przez X"; attorneys listed
  after "udziela pełnomocnictwa:" without a title ("1. X – adwokat", "X (radca prawny, …) oraz Y", one per line, ALL CAPS);
  classification signal accepts "udzielają" (consortium scan was ambiguous 4:4 with odwolanie).
- `eval/prep_skany.py`: lays out `dane/skany` + `dane/negatywne` as input/gold trees for the scorer.
- Tests: `tests/test_new_uzp_data.py` (KIO ruling rejected, code 12, prep layout), `tests/test_pipeline.py` updated for
  `{}` and the modes.
