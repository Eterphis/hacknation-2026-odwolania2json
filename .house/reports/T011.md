## What was done
- Vendored the kit into `web/static/coldtrace/`: `bundle.css`, `bundle.js`, `grit-dark.png`, `grit-light.png`, Eterphis SVGs, `eterphis-mark.css` (lockup + colour variables extracted from the kit's Logo preview, static mark only), `fonts.css` + `fonts/*.woff2`. Only edits to the kit: the two `url(/_blob/...)` grit references now point at the local PNGs and the Google Fonts `@import` line was removed (replaced by `fonts.css`).
- `web/app.py`: `GET /` now returns the HTML with the Eterphis mark and wordmark inlined (an `<img>` cannot follow night/daylight; the kit's CSS variables only reach inline SVG). JSON API, routes and response shape unchanged.
- `index.html` / `app.css` / `app.js` rewritten from kit markup: top bar with 40px Eterphis lockup and the Daylight toggle (night default, before-paint theme snippet, `ColdTrace.setTheme`), `.ct-wrap`, section heads with `.ct-ruler`, one bus ruler under the title. Upload is a `.ct-frame--well` drop zone plus a `ct-field` for the case name; one prime key ("Przetwórz sprawę", becomes "Przetwarzanie" with `aria-busy`), ground keys for clear/ZIP/copy/download. Progress is the Loaders sweep trace with the OCR hint. Per document a `.ct-frame--ice` panel: tag (live = Rozpoznany, fault = Odrzucony with a copper edge), class as panel title, score as `.ct-readout`, class scores as traces that end in vias, reason, warnings as fault vias. Tabs are ink word + 2px signal trace ending in a via (arrow keys work). Evidence is a `.ct-table` in `.ct-table-box.ct-bar` (sticky header, tabular numbers, matched value underlined with a 2px signal line, confidence as trace + number: live >= 0.85, arc >= 0.6, copper below). JSON in Martian Mono inside a frosted well. Consistency checks are tags (Zgodne / Niezgodne / Nie dotyczy). Errors and results are toasts (`role="alert"` for faults, with the cut line) and say how to fix.
- Copy in Polish, instrument-log tone: verbs repeat in the result ("Przetwórz sprawę" -> "Przetworzono sprawę"), no exclamation marks, no emoji.
- `tests/test_web.py`: +1 test (kit served, no `/_blob/`, no Google import, fonts present, logo inlined).
