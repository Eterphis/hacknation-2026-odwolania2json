## Goal
UZP stage 2 (ease of adding classes): give the recipe engine a screen. Task: `.house/tasks/T015-ui-class-editor.md`.

## What was done
**Engine helper (generic, tested):** `check_recipe_text(text)` in `odw2json/engine/recipes.py` validates recipe YAML
without touching disk and returns all errors as `{path, line, message}`: YAML syntax, JSON schema (best match for
oneOf), bad regexes (same `_check_regexes`, now carrying `.where`), unknown normaliser/validator/strategy, missing
dictionary. Line numbers come from `yaml.compose`. `load_recipe` behaviour is unchanged.

**API (`web/recipes_api.py`, router included in `web/app.py`; `/api/process`, `/api/zip` untouched):**
- `GET /api/recipes`: keeps `classes`, adds `recipes` (name, description, field count, protected, per-file error),
  `readonly`, `protected`.
- `GET /api/recipe-template`: `recipes/_template.yaml.example` plus a skeleton generated from its fields.
- `GET /api/recipes/{name}`: YAML text, output schema text, dictionaries used.
- `POST /api/recipes/validate`, `POST /api/recipes/skeleton` (null JSON from field paths, lists for `[]` / list_of_blocks).
- `POST /api/recipes/try` (multipart: text, optional output_schema, PDFs): runs a temp copy of the recipes dir with the
  draft replacing the saved class of the same name; per document: scores of all classes incl. the draft, `matched`,
  extraction of the draft class even when another class wins (so signals can be fixed), data, evidence. Nothing saved.
- `PUT /api/recipes/{name}`: validate (class must equal name), atomic write (temp file + `os.replace`), `.bak` of the
  previous file; also writes the skeleton file named by `output_schema:` (plain `*.json` filename only, with `.bak`).
- `DELETE /api/recipes/{name}[?force=true]`: 409 for odwolanie/pelnomocnictwo/przelew without force; otherwise renames
  to `<name>.yaml.bak` (recoverable).
- Names `[a-z][a-z0-9_]{1,40}` (422). `ODW2JSON_READONLY_RECIPES=1` makes PUT/DELETE return 403 with a Polish message;
  reads, validate, skeleton and try still work (try writes only to a temp dir).

**UI (Cold Trace, role tokens only):** top bar nav (Przetwarzanie / Klasy dokumentów, hash `#klasy`); list of classes
with field-count tags and "Klasa zadania UZP" tag; editor with Martian Mono textarea + line-number gutter (error lines in
copper), skeleton textarea, error list (click jumps to the line) plus fault toast; keys Sprawdź, Szkielet z pól,
Wypróbuj na PDF (results card with score traces, evidence table, JSON), Zapisz (prime), Usuń (cut key, two-step confirm,
hidden for UZP classes and in read-only). Files: `web/static/index.html`, `classes.js`, `app.css` (appended).
Docs: "Przez interfejs" in `docs/ADDING_A_DOCUMENT_CLASS.md` + `docs/screenshots/class-editor-night-error.jpg`,
`class-try-mobile-daylight.jpg`.
