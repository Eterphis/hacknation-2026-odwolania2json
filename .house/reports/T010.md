# T010 report: noisy scanned held-out set

## What was built
- `eval/make_noisy.py` (`python -m eval.make_noisy --cases 41-50 --out <dir> [--src DIR] [--dpi 200] [--seed N]`).
  Source defaults to `$UZP_DATA/dane`. Per page: pypdfium2 render at 200 DPI -> grayscale -> rotation within +-1.5 deg
  -> Gaussian blur (0.5-1.1 px) -> uneven brightness (gradient + low-frequency bump) -> optional stamp ring / signature
  scribble (60 % of pages) -> salt-and-pepper (0.2-0.6 %) -> JPEG (quality 30-55). Pages saved as image-only PDF with
  Pillow `save_all`. Seed = SHA-256(base seed, case/file/page), so output is byte-reproducible (tested).
  Gold `*.json` copied to `<out>/gold/przyklad_NN/`.
- `tests/test_make_noisy.py`: 4 tests on a synthetic PDF (no UZP data): case parsing, determinism, image-only PDF + gold
  copy + byte-reproducibility, missing case.
- Output in `a folder outside the repo on the teammate machine` (outside repo). No new dependencies.
