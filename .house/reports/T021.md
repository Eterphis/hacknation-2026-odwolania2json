## Goal
Read the real KIO appeal layout where a label (`Odwołujący:`, `Zamawiający:`) sits in a left column beside a wrapped
value. Task: `.house/tasks/T021-two-column-header.md`.

## What was done
- `odw2json/ingest/layout.py`: `group_lines` now post-processes its lines with `_label_before_block`. A line that starts
  with a `label:` word followed by a wide column gap (> 0.8 line heights) takes the label off and puts it at the front
  of the directly preceding lines (max 4, touching, first word at the value column's x) so the block reads
  `label: line1 / line2 ...`. Generic, no class names (AC-5). Both `build_text` and the engine's line rebuild go through
  `group_lines`, so text, evidence and bboxes agree. Plain `label: value` lines are untouched.
- `tests/test_ingest_layout.py`: 3 synthetic word-box tests (move, same-line label, no value above).
- `recipes/odwolanie.yaml` (YAML only): Odwolujacy.nazwa does not take a contact label (KRS/NIP/tel...) as the name;
  pełnomocnik imie_nazwisko skips a firm/title line ("Kancelaria ...", "radca prawny"); title strategy ending at
  `" (postępowanie nr`; `przez-pelnomocnika` also set from "reprezentowany przez radca/adw./kancelaria" (flag).
