# T007: Web prototype - upload a case, see classes, JSON and per-field evidence

## Goal
FastAPI page where a clerk uploads the PDFs of a case and sees class + score, JSON and an evidence table (task file: .house/tasks/T007-web-ui.md).

## What was done
- `web/app.py`: `GET /`, `GET /api/recipes` (from `odw2json.write.classes()`), `POST /api/process` (multipart `files`, optional `case` form field; writes uploads to a temp case folder with sanitised, de-duplicated names, calls `process_case`, returns case/documents/checks), `POST /api/zip` (builds `output/<case>/<name>.json` ZIP, rejects path tricks). Limits: 40 files, 60 MB, PDF only.
- `web/static/{index.html,app.css,app.js}`: no build step, Polish UI. Each document card has a "stamp" (class + score, or double-border red "Odrzucony"), the classification reason, per-class score bars, warnings, tabs "Dowody dla pól" (field, value, page, snippet with the value highlighted, rule, confidence bar; filterable) and "JSON" (copy, download). Case consistency checks block, ZIP button, indeterminate progress bar with OCR hint. Table collapses to stacked rows under 720px. Evidence `bbox` is passed through untouched (hook for later).
- `python -m web [--host --port]`; requirements.txt appended (fastapi, uvicorn, python-multipart, httpx), installed in the shared venv.
- `tests/test_web.py` (7 tests, TDD).
